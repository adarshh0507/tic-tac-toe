# Tic-Tac-Toe Game

A fun and interactive Tic-Tac-Toe game where you can play against an intelligent AI opponent. Built with vanilla HTML, CSS, and JavaScript.

## 🎮 Features

- ✨ Play vs AI (Computer)
- 🤖 Smart AI algorithm
- 🎨 Beautiful and responsive design
- 📱 Mobile friendly
- 🔄 Restart game anytime
- 🏆 Win/Lose/Draw tracking
- ⌨️ Keyboard support
- 🌙 Clean and modern UI

## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling & animations
- **JavaScript (Vanilla)** - Game logic & AI

## 📸 How to Play

1. Open `index.html` in your browser
2. You are **X**, Computer is **O**
3. Click on any empty cell to make your move
4. Computer will automatically play its turn
5. First to get 3 in a row wins!
6. Click "Reset Game" to play again

## 🤖 AI Algorithm

The computer uses **Minimax algorithm** to make optimal moves!
